The first beta of **Turnout**: a macOS default browser that sends every link to the right browser and profile, by rule, by habit, or by asking.

## Highlights

- **One app.** `Turnout.app` is a tiny native router (Go + Objective-C) that macOS hands every link to. The Electron picker is embedded inside it and only appears when a choice is needed.
- **Rules first.** Ordered regex handlers in `~/.config/turnout/router.yaml`, first match wins.
- **Browser profiles.** `profile: Work` opens Firefox-family browsers (including Firefox's new profile manager) and Chromium-family browsers (Chrome, Brave, Edge, Vivaldi) in the named profile.
- **Learns per site.** Turnout remembers which browser you pick for each site and starts opening it there.
- **Option-click any link** to choose a browser by hand.
- **Safelinks unwrapped.** Teams and Outlook safelinks are unwrapped before matching, so your rules see the real URL.
- **Instant picker.** It starts hidden at login and opens at the cursor with keyboard hotkeys. It's a non-activating panel, so tiling window managers leave it alone.

## Install

1. Download `Turnout-0.1.0-beta.1.dmg` below and drag **Turnout** to Applications.
2. This beta is **not notarized** yet, so clear the quarantine flag once:
   ```bash
   xattr -dr com.apple.quarantine /Applications/Turnout.app
   ```
3. Open Turnout once, then choose it in **System Settings → Desktop & Dock → Default web browser**.
4. Add rules to `~/.config/turnout/router.yaml`. See the [configuration guide](https://github.com/thedomguy/turnout/blob/develop/docs/config.md).

Apple Silicon only. Verify downloads against `SHA256SUMS`.

## Known limitations

- Not notarized (no Developer ID yet), so step 2 above is needed.
- Learned habits don't decay yet. Option-click to re-pick a site.
- No settings window or auto-update yet. Edit the YAML, then grab new releases from this page.
